# Registro Emocional 🧠

Aplicación web interactiva basada en el modelo de la **Rueda de las Emociones**, diseñada para ayudar al usuario a identificar, filtrar y registrar su estado anímico mediante un flujo de embudo (*funnel*).

🌐 **Demo en vivo:** [registro-emocional.pages.dev](https://registro-emocional.pages.dev/)

---

## ✨ Características y Funcionalidades

- **Embudo de identificación emocional:** Selección dinámica de sensaciones secundarias para categorizar con precisión la emoción raíz predominante (Ira, Felicidad, Tristeza, Sorpresa, etc.).
- **Recomendaciones en tiempo real:** Sugerencias y consejos contextuales automáticos según el estado emocional detectado.
- **Historial de registros:** Persistencia local de las entradas con timestamp exacto para que el usuario consulte su evolución temporal.
- **Feedback integrado:** Acceso directo a canal de sugerencias para iterar mejoras basadas en experiencia de usuario.
- **Modo oscuro nativo (Dark Mode):** Interfaz limpia, minimalista y diseñada para reducir la fatiga visual.

---

## 🛠️ Tecnologías y Despliegue

- **HTML5 & CSS3:** Maquetación moderna, flexbox, cards y diseño responsivo.
- **JavaScript Vanilla:** Lógica del embudo de filtrado, manipulación dinámica del DOM y persistencia con `localStorage`.
- **Cloudflare Pages:** CI/CD y despliegue continuo en el edge.
